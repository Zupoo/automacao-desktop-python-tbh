# Automação com Python

Projeto pessoal desenvolvido em Python para automatizar interações com uma aplicação desktop.

## Sobre o projeto

O projeto utiliza Python para automatizar uma sequência de ações, incluindo:

* Controle de mouse e teclado;
* Reconhecimento de elementos na tela por meio de imagens;
* Leitura e acompanhamento de arquivos de log;
* Controle de estados e tempos de espera;
* Organização da automação em funções.

## Tecnologias utilizadas

* Python
* PyAutoGUI
* PyDirectInput
* Keyboard

## Status
